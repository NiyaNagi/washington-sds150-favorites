Merge Upstream Catalog

        
Three-way merge: your current catalog + profile vs. a freshly fetched/edited catalog CSV or JSON on this machine. Presentation overrides (notes, quick keys, enable/disable) are always preserved; fact fields (frequencies, coverage, etc.) update from upstream unless you've explicitly overridden them, in which case a conflict is reported instead of silently discarding your customization.

Sources

        
Online/local fact sources (FCC ULS, FAA NASR, NOAA NWR, USCG NAVCEN, AMSAT, WWARA, IACC, WA EMD/DNR, NIFC, local Sentinel HPDB, RadioReference Premium import). Public sources are read-only network fetches cached locally; local sources only ever read files you point them at. Running Update never rewrites the catalog's free-text fields — it only reports per-row coverage and attaches traceable provenance, and requires an explicit Apply to persist any merge.
