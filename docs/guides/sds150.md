# Uniden SDS150: step by step

The scanner gets Favorites Lists, not a memory list. The installer writes them
straight into Sentinel's workspace (profile **Preset**), and you then write the
scanner from Sentinel. The six **Near Me** lists sit at the top on quick keys
1-6. What each list holds is in
[Updating every radio: In the car](../fleet-updates.md#in-the-car-sds150).

**You need:** Uniden BCDx36HP Sentinel, the scanner's USB cable, and the GPS
connected when you test.

## Files

| Path | What it is |
|---|---|
| `radio-data\sds150\exports\hpe\` | One `.hpe` per Favorites List; this is what gets installed |
| `radio-data\sds150\exports\favorites-overview.md` | Every list, its quick key and whether it is monitored |
| `radio-data\sds150\backups\sentinel-workspace\` | A zip of the Sentinel workspace, taken before every install |
| `%USERPROFILE%\Documents\Uniden\BCDx36HP` | Sentinel's workspace (the install target) |

## Steps

1. **Close Sentinel completely.** The installer will not run while Sentinel has
   the workspace open.
2. **Install the lists.** In `Update Radios.cmd`, tick only the SDS150, tick
   **Write to the radios**, and press **Update selected**. From a terminal:

   ```powershell
   .venv\Scripts\wasds150.exe --home .wasds150-home fleet update --radios sds150 --execute
   ```

   It exports, runs a dry run, backs up the workspace, installs every enabled
   list into profile Preset and verifies the result. If anything fails, it
   puts the backup back.
3. **Set the scanner profile.** The installer never writes `profile.cfg`, so
   check these once, either in Sentinel for profile Preset or on the scanner
   after writing:
   - **Service Types: all on.** On the scanner, press FUNCTION then ZIP/SERVICES
     and turn each type on with E/YES. If Aircraft, Business, Railroad, Other,
     Interop, Federal or Military is off, Near Me Air, Business & GMRS and most of
     Rail & Marine stay silent.
   - **Select Lists to Monitor: Full Database off.** The scan is then the Near
     Me lists.
   - **WX Operation:** Program SAME = King County **053033**, Weather Alert =
     Named FIPS Code, WX Alt Priority = On.
   - **Close Call:** Set CC Mode = **CC DND**.
4. **Reopen Sentinel**, open profile Preset and spot-check a few lists (Near Me
   - Public Safety is first).
5. **Write the scanner.** Connect the SDS150 by USB and write from Sentinel.

## Check on the scanner

- With GPS connected, the scanner starts on the Near Me lists and nothing
  else.
- FUNCTION + ZIP/SERVICES shows every service type on.
- A tower or ground frequency near home is audible on Near Me Air.

## Undo

Close Sentinel. Take the newest zip in
`radio-data\sds150\backups\sentinel-workspace\` and extract it over
`%USERPROFILE%\Documents\Uniden\BCDx36HP`. Then write the scanner again.
